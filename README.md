# TWRP device tree for OnePlus Turbo 6X (kof)
This device tree was build by [coolzyd9107](https://github.com/coolzyd9107) and [zhuzhuzihan](https://github.com/zhuzhuzihan).

To clone the tree for twrp building, run this command in your twrp source code directory:
```bash
git clone https://github.com/coolzyd9107/twrp_device_tree_kof.git device/oneplus/kof
```
And please note that this tree was set to work with TWRP branch 14.1, to work with branch 12.1 or earlier branches will require some modification by yourself
